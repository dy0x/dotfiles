# Dayfox for Brave

A local Chromium theme using Ghostty's Dayfox foreground and background, with
the frame colour from EdenEast/nightfox.nvim's Dayfox palette.

Open `brave://extensions`, enable **Developer mode**, choose **Load unpacked**,
and select this directory. This is a theme manifest with no scripts or permissions.

Brave controls which colours apply to its vertical tabs and new tab page. This
theme does not add sidebar transparency or recolour websites.

Remove it using **Settings → Appearance → Reset to default**.

Palette source: https://github.com/EdenEast/nightfox.nvim
